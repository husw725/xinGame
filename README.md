# 知识大冒险：遗忘魔王

面向**人教版二年级升三年级**（8–9 岁）小朋友的单机 H5 剧情 ARPG。
16-bit 像素风 · 手机竖屏 · 完全离线可玩 · 进度存在浏览器本地。

> 暑假第一天，你翻开课本——字和数字正在一个个消失。
> 遗忘魔王偷走了记忆水晶，知识精灵都变成了怪物……

## 直接开始玩

👉 **[点这里开始](https://husw725.github.io/xinGame/)**（手机浏览器打开最佳）

## 玩法

勇者斗恶龙式的回合制战斗，但**攻击 = 答题**。

| 你的行动 | 结果 |
|---|---|
| 答对 | 造成伤害 + 格挡，敌人反击减半 |
| 答错 | 不出手，敌人全额攻击 + 立刻显示正确答案和口诀讲解 |
| 连对 3 题 | 暴击 ×2 + 完美格挡（本回合免伤）+ 回 2 MP |

- **打怪升级**：等级和装备不够时，答对了也打不动 Boss，必须去练级攒钱
- **五部位装备**：武器 / 帽子 / 盾牌 / 鞋子 / 护符，卖出回收 75%，最好的装备只在宝箱里
- **魔法**：治疗分初中高三级，攻击魔法无视防御，还有归乡术、探宝术等野外魔法
- **错题复仇**：答错的题会变成「怨念怪」出现在村口，打败它才算真正学会
- **推箱子迷宫**：把写着得数的石箱推到写着口诀的凹槽上，三间石室全解开才能打开石门
- **记忆碎片**：8 页日记散落在支路和隐藏处，拼出遗忘魔王到底是谁

## 第一章内容

**乘法口诀沙漠** — 表内乘法、万以内加减、生字形近字、量词、反义词、二年级必背古诗。

## 给家长的说明

- 不做倒计时压力、不做体力值、死亡不掉等级不掉道具
- 谜题永远有「↺ 重来」和「💡 求助」，绝不卡关
- 答错立刻给正确答案 + 口诀讲解，学习闭环藏在战斗节奏里
- 数学题程序生成（无限量），语文题为手工题库

## 开发

纯静态，无需构建、无需后端。

```bash
python3 -m http.server 8321   # 然后打开 http://localhost:8321
```

自动化校验脚本（这些地方错了会卡死玩家，所以每次改动都该跑）：

```bash
node balance_sim.js    # 数值平衡：验证等级墙成立、堆装备不能绕过
node puzzle_check.js   # 推箱子关卡可解性（BFS 穷举）
```
